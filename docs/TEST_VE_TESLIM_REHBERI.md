# SignalGap Test ve Teslim Rehberi

1. `npm install` ardından `npm start` çalıştır.
2. `http://localhost:3000/health` adresinden sunucuyu kontrol et.
3. Postman'da `postman/SignalGap.postman_collection.json` koleksiyonunu içe aktar.
4. Sırasıyla POST /gaps, GET /gaps, GET /gaps/:id, PUT /gaps/:id, DELETE /gaps/:id isteklerini çalıştır ve her birinin gerçek ekran görüntüsünü al. Silme için 204 dönebilir.
5. Gerçek test ekran görüntülerini `screenshots/` klasörüne ekleyip GitHub'a gönder.
6. Formda proje tasarımı PDF'ini, kurulum notu PDF'ini ve ekran görüntülerini ilgili alanlara yükle.
7. GitHub bağlantısı: https://github.com/belinaybirkan/signalgap-backend
